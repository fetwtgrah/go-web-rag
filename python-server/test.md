# 华中科技大学软件工程学习资料

## 学校简介

华中科技大学位于湖北省武汉市，是教育部直属的综合性研究型大学。学校拥有较完整的工科、理科、医学和管理学科体系，在计算机科学、软件工程、人工智能等领域具有较强的教学和科研实力。

## 软件工程专业

软件工程专业主要学习程序设计、数据结构、算法、数据库、操作系统、计算机网络和软件工程等课程。学生需要掌握软件开发的基本流程，并能够使用不同的编程语言完成实际项目。

## 编程语言

软件工程学习中常见的编程语言包括 C++、Java、Python 和 Go。C++ 常用于数据结构、算法以及系统开发，Java 常用于后端服务开发，Python 在人工智能和数据分析领域应用广泛，Go 则常用于高性能后端服务和云原生开发。

## 后端开发

后端开发主要负责服务器、数据库、API 和业务逻辑等内容。一个典型的后端系统通常包括 HTTP 服务、业务层、数据访问层和数据库。Gin 是 Go 语言中常见的 Web 框架，可以用于快速开发 RESTful API。

## 人工智能

人工智能是软件工程学生可以选择的重要发展方向之一。常见的学习内容包括机器学习、深度学习、大语言模型和人工智能应用开发。Python 在人工智能领域拥有大量成熟的工具和框架，因此是学习 AI 的常用语言。

## RAG

RAG 的全称是 Retrieval-Augmented Generation，即检索增强生成。RAG 系统通常先从外部知识库中检索与用户问题相关的信息，再将这些信息提供给大语言模型，从而让模型能够基于指定知识回答问题。

一个基础的 RAG 流程可以分为文档切分、向量化、向量存储、相似度检索和生成回答几个步骤。文档首先被切分成多个文本块，然后使用 Embedding 模型将文本转换成向量，并保存到向量数据库中。

## Embedding

Embedding 是一种将文本转换成数值向量的技术。语义相近的文本通常会得到比较接近的向量，因此可以通过计算向量之间的相似度来进行语义搜索。

例如，“软件工程专业学习哪些课程”和“软件工程主要有哪些课程”虽然文字不同，但是表达的意思比较接近，因此它们的向量通常也比较接近。

## Ollama

Ollama 可以在本地运行大语言模型和 Embedding 模型。使用 Ollama 时，应用程序可以通过 API 向本地模型发送请求，从而完成文本生成或者文本向量化。

在 RAG 项目中，可以使用 Ollama 的 Embedding 模型将文档和用户问题转换成向量，然后将这些向量交给向量数据库进行相似度搜索。

## Qdrant

Qdrant 是一种向量数据库，主要用于存储和搜索向量数据。RAG 系统可以将文档经过 Embedding 后得到的向量保存到 Qdrant 中。

当用户提出问题时，系统首先将问题转换成向量，然后在 Qdrant 中搜索最相似的文本块。搜索结果可以作为上下文交给大语言模型。

## PostgreSQL

PostgreSQL 是一种关系型数据库，适合存储结构化业务数据。例如用户信息、聊天记录、文档信息和系统配置等数据都可以保存到 PostgreSQL 中。

在一个同时使用 PostgreSQL 和 Qdrant 的 RAG 系统中，可以让 PostgreSQL 负责保存业务数据和文档元数据，而 Qdrant 负责保存文本向量和执行向量检索。

## Go 与 Python

Go 和 Python 可以通过 HTTP API 进行通信。例如 Go 服务负责处理用户请求，Python 服务负责执行 AI 或 RAG 相关任务。

一种常见的架构是：

Go Gin Server → Python FastAPI Server → Ollama → Qdrant

Go 服务接收到用户问题后，通过 HTTP POST 请求将问题发送给 Python 服务。Python 服务完成向量检索和模型调用后，再将结果通过 JSON 返回给 Go 服务。

## 学习建议

学习 RAG 时，可以先实现一个最简单的版本，不需要一开始就加入复杂的重排序、混合检索和 Agent。

推荐的学习顺序是：

1. 准备 Markdown 文档。
2. 将 Markdown 文档切分成多个文本块。
3. 使用 Ollama Embedding 模型生成向量。
4. 将向量和文本保存到 Qdrant。
5. 将用户问题转换成向量。
6. 在 Qdrant 中检索最相关的 Top-K 文本块。
7. 将检索结果交给大语言模型生成最终答案。

完成基础 RAG 后，再逐步学习重排序、混合检索和 Agent。
